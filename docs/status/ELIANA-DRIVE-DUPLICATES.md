## Criterios para Versión Canónica

1. Mayor número de capítulos (más completo)
2. Fecha de modificación más reciente
3. Formato más estructurado (con índice)
4. Contenido sin errores evidentes
5. Presencia de portada

## Versiones Conservadas

Las versiones no canónicas se conservan como:
- **versión anterior**: Contenido histórico
- **borrador**: Versión preliminar
- **edición alternativa**: Versión con enfoque diferente
- **archivo histórico**: Preservación documental
