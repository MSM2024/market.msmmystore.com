# ELIANA — Exclusiones de Google Drive

## Documentos Excluidos de la Biblioteca Viva

Los siguientes tipos de documentos NO se importan como conocimiento de ELIANA:

### Financieros y Bancarios
- Declaraciones de impuestos
- Estados de cuenta bancarios
- Comprobantes de pago
- Facturas personales

### Credenciales y Seguridad
- Contraseñas
- Claves de API
- Tokens de autenticación
- Códigos de recuperación

### Identificación Personal
- Carnés de identidad
- Pasaportes
- Licencias de conducir
- Documentos legales personales

### Privados de Terceros
- Conversaciones privadas de clientes
- Información médica privada
- Direcciones privadas no autorizadas
- Datos de menores de edad

### Propiedad Intelectual de Terceros
- Libros comerciales escritos por otros autores
- Material con copyright no perteneciente a Miguel Soria Martínez
- Contenido sin licencia de uso

## Biblioteca de Referencia (Separada)

Los siguientes libros de referencia de otros autores se mantienen en una categoría separada que NO se mezcla con las OBRAS DE DON MIGUEL:

- La ciencia de hacerse rico
- El poder del ahora
- El secreto
- Obras de otros autores

## Notas
- Las exclusiones son reversibles mediante aprobación expresa de Don Miguel
- Los archivos originales permanecen intactos en Google Drive
- El catálogo registra cada exclusión con su motivo
